## 🏷️ Release Notes

### Version 1.0.0 (2026-09-11)

**Initial Release**

This is the first public release of the Affiliate Framework. It includes:

- Complete framework for building static affiliate websites
- JSON-based product configuration
- Python site generator
- Customizable HTML templates
- Support for GitHub Pages and other static hosts

**Features**:
- Add unlimited affiliate products via JSON
- Generate static HTML site with one command
- Deploy to any static hosting service
- Customizable templates and styles
- Lightweight with no dependencies

**Usage**:
1. Edit `products.json` with your products
2. Run `python3 generate_site.py`
3. Deploy the `dist/` folder
